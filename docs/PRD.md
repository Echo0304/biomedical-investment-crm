# PRD：生物医药投资项目全流程与投后数据管理平台

## 1. 文档信息

- 产品形态：无代码 CRM MVP
- 搭建工具：Twenty CRM
- 项目性质：个人产品实践
- 数据要求：只使用匿名化/虚构数据

## 2. 背景

投资项目推进涉及项目发现、初步判断、企业访谈、材料补充、尽职调查和投决等环节。信息分散时，团队难以快速确认项目阶段、材料缺口、风险和下一步行动。本项目希望用低成本方式验证一套统一项目管理模型。

## 3. 用户故事

1. 作为投资助理，我希望快速查看每个项目缺少哪些材料，以便及时催收。
2. 作为项目负责人，我希望查看所有项目的阶段和风险，以便安排精力。
3. 作为管理者，我希望按阶段查看项目池，以便判断漏斗结构。
4. 作为协同人员，我希望看到联系人、任务和截止日期，以免重复沟通或遗漏。

## 4. 功能需求

### FR-01 项目档案

用户可以创建项目并维护名称、金额、日期、赛道、来源、材料完整度、风险和阶段。

### FR-02 阶段管理

阶段包含：线索收集、初步筛选、项目访谈、尽职调查、投决会、已投资、已终止。

### FR-03 多视图

- 表格：快速编辑和横向比较；
- 看板：按项目阶段分组；
- 日历：按计划日期展示。

### FR-04 关系管理

项目可关联企业、联系人和负责人。

### FR-05 任务与记录

项目可关联沟通记录和跟进任务，任务包含负责人、截止时间与状态。

## 5. 非功能需求

- 数据匿名化；
- 字段命名明确；
- 关键状态使用枚举，避免自由文本；
- 主要操作无需编程；
- 演示页面在 3 分钟内讲清楚核心流程。

## 6. MVP 边界

不包含：真实投决审批、企业估值模型、财务系统集成、真实机构权限体系、真实投后数据接口。

## 7. 验收标准

- 至少有 4 个不同阶段的匿名项目；
- 所有项目都有赛道、来源、材料完整度、风险和阶段；
- 表格、看板、日历均可正常展示；
- 至少有 1 条沟通记录和 1 个跟进任务；
- 页面中不出现真实项目或机构敏感资料。

## 8. 后续迭代

1. 增加项目评分：团队、技术、市场、财务、合规；
2. 增加材料清单子表与完成率；
3. 增加逾期提醒和阶段停留预警；
4. 增加投后经营指标和风险事件；
5. 增加管理驾驶舱与漏斗分析。
