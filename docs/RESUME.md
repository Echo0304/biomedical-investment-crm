# 简历项目描述备选

## 产品经理方向

**生物医药投资项目全流程管理平台｜个人无代码产品实践**

- 基于创投机构投资助理工作观察，梳理项目状态分散、材料难追踪和任务易遗漏等痛点，定义投资助理、项目负责人和管理者的核心使用场景；
- 将非标准投资推进流程抽象为“线索—初筛—访谈—尽调—投决—投资/终止”7 个阶段，设计赛道、来源、材料完整度、风险等级等结构化字段；
- 使用 Twenty CRM 搭建表格、阶段看板和项目日历 MVP，并以 4 个匿名项目验证多阶段、多赛道和风险管理流程；
- 设计沟通记录与材料跟进任务链路，输出功能优先级、指标体系和迭代路线，规划项目评分、自动预警和投后数据看板。

## 运营管培生方向

**生物医药投资项目协同与数据运营平台｜个人实践**

- 将投资项目材料、阶段、风险和跟进任务统一结构化，建立项目来源、材料完整度和风险等级等运营标签；
- 搭建项目总表、阶段看板和关键日期日历，支持按项目状态识别优先级和跟进节点；
- 设计材料催收和任务责任人机制，形成可复用的项目跟进标准流程；
- 使用匿名示例数据完成流程验证，未使用任何真实企业或机构敏感信息。

## 商务管培生方向

**企业项目跟进 CRM｜个人无代码实践**

- 围绕企业线索发现、沟通、材料补充、尽调和决策流程，设计项目阶段和联系人管理体系；
- 通过项目来源、行业赛道、风险等级和材料状态对商务机会进行分层，提高跟进动作的可见性；
- 用任务、截止日期和沟通记录串联企业联系人与项目负责人，形成标准化跟进闭环；
- 搭建可演示的 Twenty CRM MVP，并规划提醒、审批和漏斗分析等后续能力。

## 使用提醒

- 根据岗位只选择一套表述，不要三套同时放入简历；
- 项目名称后明确写“个人无代码产品实践”；
- 不写“上线后提升 XX%”，因为尚未进行真实多人使用验证；
- 面试时主动说明数据已匿名化，不展示粤科或项目方真实材料。
